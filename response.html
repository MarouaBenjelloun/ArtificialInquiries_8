Authentification et droits d'accès

Authentification Omeka S · Session PHP · Accès protégé

Les réponses publiques sont consultables sans connexion. Pour créer, modifier ou supprimer une réponse, connectez-vous avec les clés API personnelles de votre compte sur l'instance Omeka S partagée.

Comment se connecter ?

  1. Connectez-vous à votre compte sur l'instance Omeka S partagée .
  2. Accédez à votre profil utilisateur, puis à la rubrique des clés API, si votre compte le permet.
  3. Utilisez vos propres clés API ou générez-en de nouvelles si nécessaire.
  4. Cliquez sur « Se connecter avec Omeka S ».
  5. Renseignez votre Key Identity et votre Key Credential dans le formulaire de connexion hébergé sur Alwaysdata.
  6. Après validation, accédez au tableau de bord et aux opérations de gestion des réponses.
Se connecter avec Omeka S Tableau de bord

Les clés API sont transmises au backend PHP via HTTPS. Elles ne sont pas intégrées au code public GitHub Pages. Les opérations sont soumises aux permissions du compte Omeka S utilisé. Les connexions GitHub, Google et CAS ne sont pas configurées.

Procédure de test du CRUD

  1. Connectez-vous avec vos propres clés API Omeka S.
  2. Cliquez sur « Créer une réponse » et renseignez le titre, l'identifiant de tâche, le code animal et le contenu.
  3. Enregistrez la réponse dans Omeka S.
  4. Revenez sur cette page et cliquez sur « Actualiser » pour consulter la réponse publique.
  5. Sans vous déconnecter, ouvrez « Modifier / supprimer mes réponses ».
  6. Sélectionnez la réponse créée, modifiez son contenu et enregistrez les modifications.
  7. Supprimez uniquement votre réponse de test.
  8. Actualisez la bibliothèque pour vérifier la disparition de cette réponse.

Pour protéger les données des autres utilisateurs, les modifications et suppressions depuis cette interface sont limitées aux réponses créées pendant la session Omeka S courante, sous réserve des permissions du compte. Effectuez donc les tests de création, modification et suppression avant de vous déconnecter.

Les réponses créées sont associées à l'exercice 8 (item 24). L'identifiant de tâche et le code animal sont enregistrés dans l'identifiant de la réponse. Les relations vers les ressources de tâche et de modèle sont affichées lorsqu'elles sont présentes dans Omeka S.
